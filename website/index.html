examples/04_causal_blog.eng SYNTAX: ENGINE LANG
// Inviolable Domain Invariants proven at Compile Time
type Slug = Text where len(self) >= 3 && len(self) <= 80;
type Email = Text where contains(self, "@");
type ViewCount = Int where self >= 0;

// Single-Level Store: Hardware-Direct NVRAM Persistence
@persistent
entity Post {
  id: UUID,
  title: NonEmptyText,
  slug: Slug,
  views: ViewCount,
  embedding: Vector[1536],
  invariant { len(title) > 0 }
}

// Native Causal Pipeline & Vector Cosine Match
fn recommend_posts(query_vec: Vector[1536]) {
  Post::all()
    |> filter(|p| p.views > 100)
    |> sort_by(|p| p.embedding <=> query_vec)
    |> take(5);
}

The 5 System Layers

Organized to give developers, systems engineers, and autonomous AI agents clear, verifiable boundaries from source syntax to raw bare metal.

LAYER 01 Deterministic Syntax & SMT LL(1) recursive descent parser without backtracking; automated compile-time proof of type refinements via Z3 SMT-LIB2. compiler/src/parser.rs
LAYER 02 Single-Level Store (SLS) Persistent memory engine bound to NVRAM / CXL. Eliminates external databases with cache-line flush primitives (CLWB + SFENCE). compiler/src/memory.rs
LAYER 03 Causal Mesh & Bridges Planetary Delta-CRDT vector clocks without coordinators, embedded PostgreSQL v3.0 protocol responder, and reactive HTTP gateway. compiler/src/bridge.rs
LAYER 04 Silicon Codegen & OS Zero-UB machine code emitter with AVX2/AVX-512 SIMD vector cosine distance, and freestanding UEFI 2.10 PE32+ unikernel builder. compiler/src/codegen.rs
LAYER 05 Genesis Toolchain & MSR CLI toolchain (`enginec`), LSP 3.17 daemon, multi-stage Docker Genesis containers, and MSR JSON 2.1 open protocol compliance. compiler/src/main.rs
