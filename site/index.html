System Architecture

The 5 Architectural Layers

A cohesive stack engineered from the first principles of modern hardware, NVRAM, and automated mathematical logic.

Layer 1

Deterministic Syntax & Z3 SMT

Zero-backtracking LL(1) grammar with 14 precedence levels and first-class refinement types (where). Pre-conditions and invariants are mathematically proven at compile-time via Z3.

compiler/src/lexer.rs · parser.rs · smt.rs
Layer 2

Single-Level Store (SLS)

Hardware-direct persistence eliminating the database server. Directly maps memory to NVRAM / CXL with 64-byte cache-line flushes (clwb + sfence) and CRC-64/NVME integrity.

compiler/src/memory.rs · data/engine.db
Layer 3

Causal Wire Mesh & Protocols

P2P Delta-CRDT vector clock synchronization across planetary nodes without master coordinates, paired with an embedded PostgreSQL wire bridge and reactive HTTP gateway.

compiler/src/mesh.rs · bridge.rs · web.rs
Layer 4

Silicon Codegen & Unikernel

Direct machine instruction synthesis (AVX-512, NEON, zero undefined behavior) and freestanding UEFI PE32+ unikernel boot image generation without Linux kernel baggage.

compiler/src/codegen.rs · unikernel.rs
Layer 5

Genesis Toolchain & MSR

Developer-centric ecosystem: reference compiler (enginec), LSP 3.17 daemon, multi-stage Docker Genesis containers, and MSR JSON 2.1 metadata conformance.

compiler/src/main.rs · Dockerfile · msr.json
